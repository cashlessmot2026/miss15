# Invitación digital — Yalena Yisel Peña Bertel

## Iniciar el proyecto
1. Instala Node.js (versión LTS).
2. Abre una terminal dentro de esta carpeta.
3. Ejecuta `npm install`
4. Ejecuta `npm run dev`
5. Abre la dirección local que muestra Vite.

## Personalizar WhatsApp
El botón de confirmación ya está configurado para enviar las respuestas al WhatsApp +57 314 728 7039. Para cambiarlo, edita `WHATSAPP_NUMBER` en `src/App.jsx` usando el código de país y solo dígitos.

## Introducción animada
Al entrar al enlace se muestra primero la intro del sobre (`src/components/yalena-intro/`). Al pulsar **Abrir invitación**, el sobre se abre y con una transición suave aparece la landing page. La corona 3D azul con fondo transparente está en `public/images/corona-azul.png`.

## Fecha
La cuenta regresiva termina el 31 de diciembre de 2026 a las 7:00 p. m. (hora Colombia).

La invitación incluye una sección dedicada que informa a los invitados que habrá lluvia de sobres.
